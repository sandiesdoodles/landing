# Sandies Doodles

Family-raised Goldendoodles in Hobe Sound, Florida.

## Run locally

```bash
cd ~/Projects/sandies-doodles
python3 -m http.server 5173
```

Open http://localhost:5173

## Content

- [`data/litter.js`](data/litter.js) — litter status, pricing, FAQs, parents, alumni pups
- [`ops/`](ops/) — buyer tracker, deposit agreement, transport policy, social captions

## Litter 2 numbers

- 8 pups · 3 boys · 5 girls
- ~$3,800 · $500 deposit (opens after individual updates)
- Go-home: 8+ weeks + vet clearance + CVI + full payment
